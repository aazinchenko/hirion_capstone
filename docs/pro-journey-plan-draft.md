# Черновик: сценарий для платного пользователя (подписка PRO)

Статус: ЧЕРНОВИК, ничего не начато (2026-10-05). Ждёт решений человека (раздел 7) и команды «старт».
Не является спецификацией: все факты о Pro ниже проверяются живой пробой (шаг 3) перед proposal.

## 1. Главная проблема: правила проекта

Сейчас Pro-сценарий прямо запрещён:
- `AGENTS.md`: «Never start Premium Trial or any payment.»
- `docs/intent.md` → «Not doing»: тесты регистрации обязаны выбирать Free.
- `docs/current-state.md`: тестовый пользователь всегда Free.

Значит, работа начинается с решения человека изменить правила, а не с кода.

Путь к Pro без денег — **Premium Trial** (`docs/intent.md:41-53, 82-83`, CONFIRMED live 2026-09-25):
- на шаге 4 регистрации Premium Trial выбран по умолчанию;
- «7 days free», без оплаты; потом аккаунт сам переходит на Free;
- Plan & Billing: «You're on the Pro plan.», «Renews on <дата + 7 дней>», «Cancel subscription»,
  «Manage subscription».

Настоящая оплата — **никогда**: это реальные деньги на рабочем сайте, тестовый режим Stripe там не работает.
Путь «купить Pro» проверяется только до ввода карты (ссылка ведёт на Stripe, ничего не заполняем).

## 2. Новые риски (по сравнению с Free-сценарием)

| Риск | Почему важно | Предложение |
|---|---|---|
| Расходы владельца сайта | Tailor my CV / Cover Letter / Help me stand out вызывают ИИ — платит владелец | Отдельное согласие владельца; каждая ИИ-кнопка максимум 1 раз за прогон и только с флагом `-Dqa.ai=true` (по умолчанию выключен) |
| Защита от злоупотребления триалом | Сайт может ограничивать триал по email / устройству / IP | Узнать у владельца; один триал-аккаунт за прогон |
| Подписка в Stripe | Если триал создаёт подписку в Stripe, удаление аккаунта может её не отменить | Проверить вживую; при необходимости `JourneyCleanup` сначала делает Cancel subscription, потом Delete account |
| Ответы ИИ меняются | Правило: тексты ответов ИИ не проверяем | Проверяем только структуру: результат появился, не пустой, есть кнопки Copy / Download |
| Переход на Free через 7 дней | В рамках прогона не дождаться | Вне автотестов, только ручная проверка |

## 3. Что неизвестно — живая проба перед спецификацией

Правило проекта: факт из кода сайта считается ASSUMED, пока не увиден вживую.
Нужна **одна живая проба**: один триал-аккаунт, факты записываются в `docs/intent.md`, аккаунт удаляется.
Проводит человек вручную или агент только после явного «да».

Что выяснить:
1. Просит ли триал карту (в `intent.md` записано «no payment» — подтвердить).
2. Что показывают ИИ-кнопки: окно, страницу или файл; сколько ждать; есть ли дневной лимит.
3. Cancel subscription: тексты окна подтверждения и что показывает Plan & Billing после отмены.
4. Куда ведут «Manage subscription» и «Upgrade»: портал Stripe или checkout (смотрим только ссылку).
5. Как выглядит Analytics у Pro: разделы A / B / C и метрики. Это откроет отложенный DASH-8
   (формула Save rate есть в `intent.md:71`).
6. Удаляется ли аккаунт с активным триалом без ошибок.

## 4. Проект сценариев — новая спецификация `pro-subscription`

Точные тексты — после пробы.

| ID | Требование | Сценарии |
|---|---|---|
| PRO-1 | Регистрация с Premium Trial заканчивается на Dashboard | Шаги 1–4 без смены тарифа, «See my matches» → `/dashboard`, вход выполнен |
| PRO-2 | Plan & Billing показывает Pro-триал | «You're on the Pro plan.»; «Renews on» = дата регистрации + 7 дней; есть «Cancel subscription», «Manage subscription» |
| PRO-3 | Pro видит ИИ-кнопки на карточках | На первой карточке «Tailor my CV», «Write Cover Letter», «Help me stand out»; у вкладки Analytics нет значка Pro |
| PRO-4 | Analytics открыта без плашки | Нет «Unlock Hirion Pro»; видны «Your performance», «Swiss market intelligence», «Positioning & opportunity» |
| PRO-5 (= DASH-8) | Save rate считается верно | Save одной вакансии → «Jobs in feed» уменьшилось на 1, Save rate = round(saved / (saved + feed) × 100) % |
| PRO-6 | Tailor my CV выдаёт результат | Один клик; результат появился и не пустой; текст не проверяем (только с `-Dqa.ai`) |
| PRO-7 | Write Cover Letter выдаёт результат | То же |
| PRO-8 | Help me stand out выдаёт результат | То же |
| PRO-9 | Ссылки на оплату ведут к Stripe | Проверяем адрес ссылки у «Manage subscription» / «Upgrade»; не переходим, карту не вводим |
| PRO-10 | Отмена подписки | «Cancel subscription» → подтверждение → новый статус в Plan & Billing (текст после пробы) |
| PRO-11 | Удаление Pro-аккаунта | Существующий `JourneyCleanup` (при необходимости после PRO-10) |

Не входит: реальная оплата, переход на Free через 7 дней, письма о триале, тексты ответов ИИ.

Итого около 11 тестов (8 без флага `-Dqa.ai`).

## 5. Архитектура

- Отдельный набор `testng-pro.xml`, подключается в `testng-all.xml` третьим файлом.
  Free-journey остаётся без изменений (40 тестов). Полный прогон создаёт два аккаунта: Free и Pro.
- Классы: `ProSignupTest` (PRO-1, PRO-2), `ProDashboardTest` (PRO-3…PRO-8),
  `ProBillingTest` (PRO-9, PRO-10), в конце тот же `JourneyCleanup`.
- `TestUser` получает поле `plan` (free / trial). Защита `\+hirion-qa-\d+@` не меняется и не ослабляется.
- Хук `scripts/guard-live-run.mjs` дополнительно спрашивает разрешение на `-Dqa.plan=trial` и `-Dqa.ai=true`.
- Файлы человека (`support/**`, хук, xml-наборы) меняет человек или ревьюер по его заданию;
  тесты пишет агент через `/opsx:apply`, как в изменениях 3 и 4.
